# Bootstrap pin for pip itself, kept in a file because `--hash` is a
# requirements-file option only -- pip 26 rejects it on the command line
# ("no such option: --hash"), so `pip install pip==X --hash=...` cannot work.
# Both artifacts are listed (wheel first, sdist as the fallback pip would
# build from); --require-hashes accepts whichever it resolves to.
#
# [!] osv-scanner reads this file, so the pin is now a scanned dependency and
# pip's own CVEs apply to it. 26.1.1 was vulnerable to CVE-2026-8643 (entry
# points installed outside the target directory) and CVE-2026-13346 (doubly
# encoded index URLs writing to arbitrary paths); fixed in 26.1.2 and 26.2.
# Do not pin below 26.2 again.
#
# Refresh on a pip bump:
#    curl -s https://pypi.org/pypi/pip/<version>/json \
#      | python -c "import json,sys;[print(u['digests']['sha256'],u['filename']) for u in json.load(sys.stdin)['urls']]"
